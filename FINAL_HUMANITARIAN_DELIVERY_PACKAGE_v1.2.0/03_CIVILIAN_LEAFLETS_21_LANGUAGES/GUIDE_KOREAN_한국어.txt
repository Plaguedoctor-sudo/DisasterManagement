지원 기기: Android 10 이상 (API 29+)
100% 완전 오프라인: 인터넷, 기지국, USIM 카드 없이 전술 메시 통신 수행.

--------------------------------------------------------------------------------
1. 인터넷 없이 설치하는 방법
--------------------------------------------------------------------------------
1. 파일 확인: DisasterManagement-v1.2.0-signed.apk
2. 파일을 탭하여 설치를 시작합니다.
3. "보안상의 이유로 알 수 없는 앱을 설치할 수 없습니다" 경고가 뜨면:
   - "설정" (Settings)으로 이동
   - "이 출처의 앱 허용" (Allow from this source) 활성화
   - 뒤로 돌아가 "설치" (Install) 선택
4. 홈 화면에 전술 방패 아이콘이 나타납니다.

--------------------------------------------------------------------------------
2. 오프라인 상태에서 주변 사람들에게 앱 배포하기
--------------------------------------------------------------------------------
방법 A (앱 내 핫스팟 전파):
1. 앱에서 "Share App Offline"을 누릅니다.
2. 기기가 데이터 요금이 들지 않는 로컬 Wi-Fi를 켜고 QR 코드를 생성합니다.
3. 주변 사람이 해당 Wi-Fi에 연결 후 카메라로 QR 코드를 스캔하면 APK가 즉시 다운로드됩니다.

방법 B (파일 직접 전송):
블루투스, Quick Share 또는 USB OTG 메모리 / MicroSD 카드로 복사합니다.

--------------------------------------------------------------------------------
3. 긴급 액션 버튼 기능
--------------------------------------------------------------------------------
[초록] 안전 보고 (I AM SAFE):
       주변 피어 기기들에 위치 정보와 함께 안전 상태를 암호화하여 전송.

[빨강] 고립 / 구조 요청 (TRAPPED / AID):
       최고 우선순위 SOS 신호 송출 + 붕괴 잔해 속에서 18.5 kHz 초음파 구조 신호 발생.

[노랑] 구호 물품 요청 (NEED SUPPLIES):
       식수, 식량, 비상 의약품, 대피소, 충전 전력을 1회 탭으로 요청.

[보라] 위험 보고 (REPORT DANGER):
       고압선 단선, 가스 누출, 화재, 침수, 붕괴 위험을 주변에 즉시 경고.

[해골] 긴급 데이터 파기 (PANIC PURGE):
       검문, 심문, 압수 위험 시 암호화 키와 메모리를 영구 파기하고 앱을 즉시 종료!
